
## 🇬🇧
This website was inspired by my high school days, when students had a strong desire to share their thoughts freely. What they needed was absolute anonymity and a fast, convenient way to submit posts.

Behind the scenes, the system uses Google Sheets as a lightweight and easy-to-manage database. Content moderation is also handled directly through Sheets, keeping the workflow simple and familiar for the admin team.

However, instead of forcing students to submit content through restrictive Google Forms with limited interaction, I built this custom web interface to provide a more modern, intuitive, and seamless submission experience.

If you find this project interesting or useful, feel free to give the repository a Star to support my work!
