The idea for this website came from my high school days: students had a huge desire to share their thoughts, which demanded absolute anonymity and maximum convenience when submitting posts. Behind the scenes, the system actually uses Google Sheets as a lightweight, easy-to-manage database, and content moderation is still done directly on Sheets to keep things familiar and simple for the admin team. However, instead of forcing students to submit through restrictive Google Forms that lack interaction, I developed this custom web interface to deliver a much more modern, intuitive, and smooth submission experience.

The entire source code for this project is fully open-source. Feel free to clone, download the complete code, tweak it, or build new features to adapt it for your own school or community.
